---
name: sender-ui
description: Use when changing screens or behaviour in the sender app.
---
- Design: Apple-style. Large titles, clear hierarchy, minimum 44 px tap targets, light and dark mode, large text support, VoiceOver labels.
- Keep the hold-to-send ring and the 4-second cancel window unless the user asks otherwise.
- While an alert is sending or in its cancel window, Settings and Alert info cannot be opened. When idle, the two can be switched between directly.
- Never say that rescuers have received or can see an alert. Use "Sent", not "Help is coming".
- Every error screen shows a Call 112 button.
- Use device-neutral wording ("this device"), not "phone".
- Match the user's language (Bulgarian or English).
- Run the build after changes. List every changed file with line numbers.
